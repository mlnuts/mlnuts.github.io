    Section 1.12 Hypothesis Tests

    Often we want to know if a new data contradicts an established belief. That’s when hypothesis tests are valuable in assigning a degree of confidence in decision to reject or not to reject the current belief, which are usually cast in terms of values of parameters. Ultimately, it helps decide if a difference or relationship observed in a sample is a real effect in the population or just due to random chance.
    Some of the questions settled by hypotheis testing can also be settled by examining the confidential interval. For instance, if the hypothesized value happens to be outside the confidence interval, then we would reject the hypotheis that the parameter has that value. In that regard hypothesis tests and confidence intervals are similar.
    Whether we use a confidence interval or a hypothesis test depends on the specific question at hand. For estimating population parameters, confidence interval is more appropriate. However, if we have already been given a value of some parameter and we want to know if that is true or not, then we choose hypothesis testing.
    Hypothesis tests usually follow a pattern of three steps:
    1. Begin with a starting guess or some “established/default” knowledge, called the Null Hypothesis, denoted by \(H_0\text{.}\) We also have an Alternate Hypotheis, denoted by \(H_A\text{,}\) which claims a new possibility. You need both to figure out where to look in order to be able to reject or not reject \(\H_0\text{.}\)
      If \(H_0\) or \(H_A\) completely specifies the distribution of the data, then we say the test is a simple test, otherwise it is composite test. An example will be the probability of Heads in a coin toss with outcome of a toss variable \(X\text{,}\) which is \(1\) when Head and \(0\) when Tails, i.e., a Bernoulli variable:
      \begin{equation*} H_0: p = 0.5\implies H_0 = \text{Bernoulli}(p=0.5). \end{equation*}
      This will be a hypothesis for a simple test. For an example of a compisite test, we can envision a Gaussian random variable \(X\) and the null hypothesis looks like:
      \begin{equation*} H_0: \mu = 0\implies H_0 = \mathcal{N}(0, \sigma^2 \gt 0), \end{equation*}
      where \(\sigma^2\) is unspecified, which makes \(H_0\) not fully specifying the distribution from which data would be sampled, assuming \(H_A\) is also not specifying any distribution fully.
    2. Collect data (either from your own study or from someone else’s). Compute appropriate quantities.
    3. Decide on criteria of rejecting the null hypothesis. Use probability theory to implement the criteria. This step involves a significance level of the test, which we usually designate by \(\alpha\text{,}\) whose complementary \((1-\alpha)100%\) was used to denote the confidence level in the confidence interval calculations. Here, given a significance level \(\alpha\text{,}\) we seek the probability of rejecting \(H_0\) by using the model applying the model corresponding to \(H_0\) to the data collected.
      \begin{equation*} P_{H_0}(\text{Given Data, Reject } H_0) = \alpha. \end{equation*}
    There are two ways hypothesis tests are implemented:
    1. Rejection region or critical region or critical value
    2. The p-Value.
    In this section we will first study hypothesis tests using rejection region approach. After that we will look at the p-value approach.

    Subsection 1.12.1 Hypothesis Test using Rejection Regions

    Suppose we want to know if a coin is a fair coin. We can start with the assumption that the coin is a fair coin, meaning the probability of getting Heads (\(X=1\)) is equal to the probability of getting Tails (\(X=0\)). This will be the hypothesis about the proportional parameter \(p\) of the Bernoulli distribution that we expect in \(0/1\) binary system.
    \begin{align} \amp \text{Null hypothesis, } H_0: \quad p = 0.5 \equiv p_0\tag{1.12.1}\\ \amp \text{Alternate hypothesis, } H_A: \quad p \ne p_0\tag{1.12.2} \end{align}
    Since \(H_A\) is asking us to look both above and below \(p_0\text{,}\) this test is called two-tailed test. If alternate hypothesis was claiming that \(p \gt p_0\text{,}\) we will look only the region above \(p_0\)and that would have been a one-tail test. Similarly for the case \(H_A:\ p\lt p_0\text{.}\)
    For the second step, we need to get data. So, let’s toss the coin \(100\) times. Suppose, we got \(59\) Heads and \(41\) Tails. We use real number \(1\) for the Heads and \(0\) for the Tails. From these we calculate the sample mean to compare with the mean claimed to be true by the null hypothesis. Let’s use the symbol \(\overline{p}\) for the sample mean here.
    \begin{equation} \overline{p} = \frac{1}{n}\sum_{i=1}^n\, X_i = \frac{59}{100} = 0.59.\tag{1.12.3} \end{equation}
    Clearly, \(\overline{p} \ne 0.5\text{.}\) So, should we say that claim \(H_0\) is false? Not, so fast. We need to decide on the criteria upon which we will decide on reject \(H_0\) or not.
    Suppose, we have the criteria that we will reject \(H_0\) if data gave us the sample mean beyond some value, either above or below as stated in the alternate hypothesis \(H_A\text{.}\) How would we set this threshold value? We can use the confidence level \((1-\alpha)100\%\) and an assumption about the distribution of the sample mean. If the number of data points (here \(n=100\) tosses) is large enough, we can use Central Limit Theorem, as we have done before, to assume that \(\overline{P}\) (using capital letter for the random variable) is normally distributed with the “true” characteristics given by the claims of \(H_0\text{.}\) Here, these would mean the following expectation if \(H_0\) is true:
    \begin{equation*} \overline{P} \sim \mathcal{N}\left(p_0, \frac{p_0(1-p_0)}{n} \right). \end{equation*}
    It’s easier to work with a standardized normal distribution by introducing a \(Z\) variable, find the appropriate \(Z\) values for rejecting \(H_0\text{,}\) and then recover the values of the sample mean \(\overline{P}\) for rejecting \(H_0\text{.}\) If the value \(\overline{p}\) from our data fell in the rejection regions, we will reject \(H_0\) and if not, we will not reject \(H_0\text{.}\)
    \begin{equation*} Z = \frac{ \overline{P} - p_0 }{ \sqrt{ \frac{p_0(1-p_0)}{n} } } = \frac{\overline{P} - 0.5}{0.05}. \end{equation*}
    A plot of \(Z\) helps here. Suppose, we choose the confidence at \((1-\alpha)100\% = 95\%\text{,}\) i.e., \(\alpha = 0.05\text{.}\) Our rejection values of \(Z\) will be either side of \(Z=0\) that are far away so that the net probability in the rejection regions are \(5\%\text{.}\) This is shown in Figure 1.12.1. From the \(Z=\pm 1.96\text{,}\) we find the corresponding \(\overline{P}\) values:
    \begin{align*} \amp \text{Reject }H_0 \text{ if}:\\ \amp \qquad\qquad \overline{p} \gt 0.5 + 1.96 \times 0.05 = 0.60, \quad \text{OR}\\ \amp \qquad\qquad \overline{p} \gt 0.5 - 1.96 \times 0.05 = 0.40 \end{align*}
    Our data gave us the value \(\overline{p} = 0.59\) as shown in Eq. (1.12.3). This value is not in either of the rejection regions although it is quite close to the upper region. Hence, we will not reject the null hypothesis \(H_0\text{.}\) Had we obtained \(61\) Heads, out of \(100\) tosses of the coin, we would have rejected the \(H_0\) hypothesis.

    Remark 1.12.2. Case of a One-Tail Test.

    Suppose, instead of the Alternate Hypothesi in Eq. (1.12.2), we had a different Alternate Hypothesis but the same null hypothesis.
    \begin{align} \amp \text{Null hypothesis, } H_0: \quad p = 0.5 \equiv p_0\tag{1.12.4}\\ \amp \text{Alternate hypothesis, } H_A: \quad p \gt p_0\tag{1.12.5} \end{align}
    With the same experimental result of \(59\) Heads in \(100\) tosses, as above, let us decide whether we can reject \(H_0\) at the same \(\alpha = 0.05\) level. Going through the same steps, but now, we need the entire \(5\%\) of the rejection region will now be all in the direction \(Z\gt 0\text{.}\) That gives the critical value of \(z = \Phi^{-1}(0.95) = 1.645\text{.}\) This gives the rejection region in p to be:
    \begin{equation*} \text{Reject }H_0 \text{ if}: \overline{p} \gt 0.5 + 1.645 \times 0.05 = 0.582. \end{equation*}
    The value of \(\overline{p} = 59/100 = 0.59\) is in the rejection region. Hence, we reject that the coin is fair in favor of the alternate hypothesis \(H_A\text{.}\) Same data but different alternate hypothesis gives you a different decision!

    Remark 1.12.3. What if we had chosen a different \(\alpha\) level?

    A short answer is you might have a different conclusion about rejecting \(H_0\text{.}\) That is why you cannot just go \(\alpha\)-shopping till you get the decision you want. (If you want to do \(\alpha\)-shopping, you better do the p-Value as I explain below.) You must first set the \(\alpha\) value BEFORE you do the analysis. For instance, if you had set \(\alpha = 0.10\) in the two-tail case above, you would have rejected \(H_0\) while you were not able to reject \(H_0\) at \(\alpha=0.05\text{.}\) If you had set \(\alpha = 0.06\text{,}\) you wouldn’t have rejected \(H_0\) either. So, your conclusion does depend on you level of confidence you desire. Recall the level of confidence in complement of \(\alpha\text{,}\) i.e., \((1-\alpha)100\%\text{.}\)

    Subsection 1.12.2 Type I and TypeII Errors

    In the example above regarding whether the coin is fair or not, we analyzed the data collected from \(100\) tosses assuming the coin was fair (the null hypotheis, \(H_0\)), and found that at the \((1-\alpha)100\%\) we were unable to reject \(H_0\) since our data had \(59\) Heads. We also noticed that, had we got \(61\) Heads, which is entirely possible, we would have rejected \(H_0\text{.}\)
    This shows that just a variation in data collection, can lead us to the opposite conclusion, regardless of whether \(H_0\) happens to be true or not in reality. This makes two types of error possible in our decision.
    We say that we have made a Type I Error if we rejected the null hypothesis \(H_0\) in favor of \(H_A\) even though it shouldn’t have been. The probability of rejecting \(H_0\) while assuming that \(H_0\) is the correct distribution is just the significance \(\alpha\) of the test.
    \begin{equation*} \alpha = P_{H_0}(\text{Given Data, Reject} H_0). \end{equation*}
    A Type II Error occurs when we fail to reject \(H_0\) in favor of \(H_A\) when we should have rejected it. In this case, assumign simple \(H_A\) hypothesis, we can compute the probability of rejecting \(H_0\text{.}\) This is probability of type II error, denoted by \(\beta\text{.}\)
    \begin{equation*} \beta = P_{H_A}(\text{Given Data, Do Not Reject} H_0). \end{equation*}
    Now \((1-\beta)\) would be the probability of correctly rejecting \(H_0\) if we assume \(H_A\) is the correct distribution. This is called power of the test.
    \begin{equation*} \text{Power} = 1 - \beta = P_{H_A}(\text{Given Data, Reject} H_0). \end{equation*}

    Subsection 1.12.3 The p Value Approach

    In the examples of rejection region approach, we saw that you failed to reject the null hypothesis if \(\alpha\) was too low. That is, there is a largest \(\alpha\text{,}\) oe equivalently, smallest significance lavel \((1-\alpha)100\%\) at which we will be able to reject the null hypothsis, \(H_0\text{.}\) That smallest \((1-\alpha)100\%\) is called the \(p\) value of the data.
    Traditional low \(p\) values such as \(p \lt 0.05\) or \(p \lt 0.01\) is considered statistically significant. Recall that we set the value of \(\alpha\) or \((1-\alpha)100%\) BEFORE we do the analysis. Here we would do the same and demand that the \(p\) value obtained from the data be less than \(\alpha\text{.}\)
    \begin{equation*} \text{Reject } H_0 \text{ if } p\text{-value} \lt \alpha. \end{equation*}
    Let’s look at the same example as the two-tail test presented above. Due to the misunderstanding of letter \(p\) being used for proportion in the example and the same letter used for \(p\) value, I will change the proportion symbol to \(\mu\) and the corresponding random variable to \(M\text{.}\) The hypotheses were
    \begin{align} \amp \text{Null hypothesis, } H_0: \quad \mu = 0.5 \equiv \mu_0\tag{1.12.6}\\ \amp \text{Alternate hypothesis, } H_A: \quad \mu \ne \mu_0\tag{1.12.7} \end{align}
    The data from \(n=100\) tosses had shown that \(\overline{\mu} = 0.59\text{.}\) We had introduced a standard normal variable to implement expectations assuming \(H_0\) were true.
    \begin{equation*} Z = \frac{\overline{M} - 0.5}{0.05} \sim \mathcal{N}(0, 1). \end{equation*}
    The \(Z\) value corresponding to the data is
    \begin{equation*} z = \frac{0.59 - 0.5}{0.05} = 1.8. \end{equation*}
    By inserting this in the CDF of the standard normal we find
    \begin{equation*} q = \Phi(1.8) = 0.964. \end{equation*}
    Because of the two-tail nature of the alternate hypothesis, this must correspond to \(1-\alpha_q/2\) since we would have the probability \(\alpha/2\) above it.
    \begin{equation*} 1-\alpha_q/2 = q = 0.964. \end{equation*}
    This gives \(\alpha_q = 0.072\text{.}\) That is, the \(p\)-value will be \(0.072\text{.}\) This is too high \(p\) value for rejecting \(H_0\) since \(p = 0.072 \gt \alpha=0.05\equiv p\text{th}\text{,}\) the threshold value.
    Of course, you can, then, wrongly turn around, and say, let’s go back and set \(p_\text{th} = 0.1\) just so that you can use your data to reject \(H_0\) in favor of \(H_A\text{.}\) That is why, people insist that for rejecting some well-established fact embodied in the null hypothesis, your \(p\) value must be very very small.
