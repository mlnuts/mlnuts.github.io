    Section 1.12 Hypothesis Tests

    Often we want to know if a new data contradicts an established belief presented as a hypothesis about the value(s) of one or more parameters of a statistical model. Hypotheis testing provides a process for determining whether a hypotheis should be rejected based upon the data. This topic is of fundamental importance in applications of statistics to real life.
    Suppose we have a statistical distribution of a random variable \(X\text{,}\) given by either a PMF or a PDf or a CDF which contains a parameter. For example,it may be a Binomial distribution with parameters \(n\) and \(p\text{.}\) A hypothesis here may be about the value of \(p\) for some fixed \(n\text{,}\) say \(n=100\text{.}\) Following are examples of hypotheses.
    \begin{align*} \amp (1)\ H_1:\quad p = 0.5 \\ \amp (2)\ H_2:\quad 0.6 \gt p \le 1.0 \\ \amp (3)\ H_3:\quad p \ne 0.5 \end{align*}
    Hypthesis \(H_1\) is an example of a simple hypothesis since it completely defines the distribution to be \(\text{Binomial(100, 0.5)}\text{.}\) In caqse of a simple hypothesis, we can also write hypothesis in a distribution notation.
    \begin{equation*} H_0 \sim \textrm{Binomial}(100, 0.5). \end{equation*}
    Hypothesis \(H_2\) and (or \(H_3\)) is an example of composite hopthesis since there are more than one distribution depending upon the value of \(p\text{,}\) e.g., distributions \(\text{Binomial(100, 0.7)}\) and \(\text{Binomial(100, 0.8)}\) satisfy \(H_2\text{.}\)
    There are basically two approaches to implement hypothesis testing as we will illustrate in the following sections.
    1. Rejection region or critical region or critical value
    2. The p-Value.
    Hypothesis tests usually follow a pattern of three steps:
    1. State a null hypothesis, denoted by \(H_0\text{,}\) which will usually be a simple hypothesis and an alternate hypothesis, denoted by either \(H_1\) or \(H_1\text{.}\) There is no expectation that alternate hypothesis be just the complement of the null hypothesis. For instance, \(H_0: p = 0.5\) and \(H_1: p \gt 0.5\text{,}\) which leaves the possibility that \(p \lt 0.5\) unaccounted for.
    2. We now, need to decide on a test statistic, which is a random variable. By a test statisic, \(T\) we mean a function of the data, \(f(x_1, x_2, \cdots, x_n)\text{,}\) whose distribution \(\rho_T\) can be used to find the rejection/critical region for the rejection of the \(H_0\) hypothesis. We then, collect data and compute the test statistic’s value on that data.
      For instance, sample mean \(\overline{X}\) will be the statistic for the proportion \(p\) in the Binomial distribution. Another test statistic for the \(H_0: p = p_0\) would be the normalized sample mean.
      \begin{equation*} Z = \frac{\sqrt{n}(\overline{X} -p_0) }{\sqrt{p_0(1-p_0)} }. \end{equation*}
    3. Use probability theory to draw conclusion whether null hypothesis can be rejected, either because the data was in the rejection region or that the p Value was small enough.

    Subsection 1.12.1 Simple Tests using Rejection Regions

    Problem: Suppose we want to know if a coin is a fair coin. We can start with the assumption that the coin is a fair coin, meaning the probability of getting Heads (\(X=1\)) is equal to the probability of getting Tails (\(X=0\)).
    \begin{equation*} p = 0.5. \end{equation*}
    The Hypotheses: Let us use the symbol \(p_0\) for the number \(0.5\text{,}\) just to comply with notation of using the subscript with anything that is the null hypotheis. Writing in terms of a null hypothesis and an alternate hypotheis, we will express it as follows.
    \begin{align} \amp \text{Null hypothesis, } H_0: \quad p = p_0\tag{1.12.1}\\ \amp \text{Alternate hypothesis, } H_1: \quad p \ne p_0\tag{1.12.2} \end{align}
    The null hypotheis is a simple hypothesis and it is of course specifying the Bernoulli distribution completely and we can write it more explicitly as follows.
    \begin{equation*} H_0 \sim \text{Bernoulli}(p_0) \end{equation*}
    Hypothesis \(H_1\) is a composite hypothesis. We can pick any value of \(p\) other than \(p_0\) to specify one of the infintely many Bernoulli distributons corresponding to the hypothesis \(H_1\text{.}\)
    Since \(H_1\) is asking us to look both above and below \(p_0\text{,}\) this test is called a two-tailed test. If alternate hypothesis was claiming that \(p \gt p_0\text{,}\) we will look only the region above \(p_0\)and that would have been a one-tail test. Similarly for the case \(H_1:\ p\lt p_0\text{.}\)
    The Data and the Statistic: To obtain the data, let’s toss the coin \(n=100\) times. Suppose, we get \(59\) Heads and \(41\) Tails. We use real number \(1.0\) for the Heads and \(0.0\) for the Tails.
    Our hypothesis is about the proportion \(p\text{,}\) which can be estimated by th sample mean \(\overline{X}\) of the \(100\) random variables, \((X_1, X_2, \cdots, X_{n})\) from our data collection process as we have seen before.
    \begin{equation*} \overline{X} = \frac{1}{n}\left( X_1 + X_2 + \cdots + X_{n} \right). \end{equation*}
    Using the data we get
    \begin{equation} \overline{X} = \frac{1}{100}\left(59\times 1 + 41\times 0 \right) = 0.59.\tag{1.12.3} \end{equation}
    Clearly, \(\overline{X} \ne p_0\text{.}\) So, should we say that claim \(H_0\) is false? Not, so fast. We need to decide on the criteria upon which we will decide whether this value is too far from \(p_0\text{.}\) For that we use probability theory.
    Use probability theory: Assuming \(H_0\) is true, we can work out its consequences and compare how the test statistic fits in with those consequences. Here, our experiment for finding \(\overline{X}\) is a scaled \(\text{Binomial}(n,p)\) experiment since
    \begin{equation*} X_\text{sum} = X_1 + X_2 + \cdots + X_n \sim \sim \text{Binomial}(n,p). \end{equation*}
    Assuming \(H_0\) to be true,
    \begin{equation*} X_\text{sum} \sim \text{Binomial}(n,p_0). \end{equation*}
    With large \(n\text{,}\) specifically, if \(np_0 \gt 5\) and \(n(1-p_0) \gt 5\text{,}\) which is the case here since \((n p_0 = 50, n(1-p_0) = 50)\text{,}\) the sample mean of the data can be seen to follow a Gaussian distribution
    \begin{equation*} \overline{X} = \frac{X_\text{sum}}{n} \sim \mathcal{N}(\hat\mu, \hat\sigma^2), \end{equation*}
    where
    \begin{equation*} \hat\mu = \frac{x_1 + x_2 + \cdots + x_n}{n},\quad \hat\sigma^2 = \frac{p_0(1-p_0)}{n}. \end{equation*}
    That is, if \(H_0\) is true, we expect sample mean,
    \begin{equation*} \overline{X} \sim \mathcal{N}\left(p_0, \frac{p_0(1-p_0)}{n} \right). \end{equation*}
    It’s almost always easier to work with a standard normal variable \(Z\text{,}\) which can be obtained by subtracting away the mean and scaling by the square root of the variance.
    \begin{equation*} Z = \frac{ \overline{X} - p_0 }{ \sqrt{ \frac{p_0(1-p_0)}{n} } } = \frac{\overline{X} - 0.5}{ \sqrt{ \frac{0.5(1-0.5)}{100} } } = \frac{\overline{X} - 0.5}{0.05}. \end{equation*}
    A plot of \(\rho(Z)\) is shown in Figure 1.12.1. We can visually see the areas that have to be included or exclued at a particluar confidence level.
    While we have talked about confidence level \((1-\alpha)100\%\) where we discussed the confidence interval, here, \(\alpha\) is called significance level of the test. We will see below that it represents the probability of error, so-called the type I error, that we would reject the hypothesis \(H_0\) when in actuality it ws true.
    Suppose, we choose the significane level \(\alpha = 0.05\text{.}\) Our rejection values of \(Z\) will be on either side of \(Z=0\) that are far away so that the net probability in the rejection regions add up to \(5\%\text{.}\) We use the inverse CDF of the standard normal to find the rejection regions in the \(Z\)-sampe space, which can of course, be translated in the original sample space of \((X_1, X_2, \cdots, X_n)\text{.}\)
    \begin{align*} \amp\text{Upper side: } z_{1-\alpha/2} = \Phi^{-1}(1-\alpha/2) = \Phi^{-1}(0.975) = 1.96 \\ \amp\text{Lower side: } z_{\alpha/2} = \Phi^{-1}(\alpha/2) = \Phi^{-1}(0.025) = -1.96 \end{align*}
    We need to translate these critical values of \(Z\) back to the sample space through the value of \(\overline{X}\text{.}\)
    \begin{align*} \amp \text{Reject }H_0 \text{ if}:\\ \amp \qquad\qquad \overline{X} \gt 0.5 + 1.96 \times 0.05 = 0.60, \quad \text{OR}\\ \amp \qquad\qquad \overline{X} \lt 0.5 - 1.96 \times 0.05 = 0.40 \end{align*}
    Our data gave us the value \(\overline{X} = 0.59\) as shown in Eq. (1.12.3). This value is not in either of the rejection regions. Hence, we will not reject the null hypothesis \(H_0\) in favor of \(H_1\text{,}\) even though this value is in the domain of \(H_1\text{.}\) Had we obtained \(61\) Heads, out of \(100\) tosses of the coin, we would have rejected the \(H_0\) hypothesis.

    Remark 1.12.2. Case of a One-Tail Test.

    Suppose, instead of the Alternate Hypothesi in Eq. (1.12.2), we had a different Alternate Hypothesis but the same null hypothesis.
    \begin{align} \amp \text{Null hypothesis, } H_0: \quad p = 0.5 \equiv p_0\tag{1.12.4}\\ \amp \text{Alternate hypothesis, } H_1: \quad p \gt p_0\tag{1.12.5} \end{align}
    With the same experimental result of \(59\) Heads in \(100\) tosses, as above, let us decide whether we can reject \(H_0\) at the same \(\alpha = 0.05\) level. Going through the same steps, but now, we need the entire \(5\%\) of the rejection region will now be all in the direction \(Z\gt 0\text{.}\) That gives the critical value of \(z = \Phi^{-1}(0.95) = 1.645\text{.}\) This gives the rejection region in p to be:
    \begin{equation*} \text{Reject }H_0 \text{ if}: \overline{X} \gt 0.5 + 1.645 \times 0.05 = 0.582. \end{equation*}
    The value of \(\overline{X} = 59/100 = 0.59\) is in the rejection region. Hence, we reject that the coin is fair in favor of the alternate hypothesis \(H_1\text{.}\) Same data but different alternate hypothesis gives you a different decision!

    Remark 1.12.3. What if we had chosen a different \(\alpha\) level?

    A short answer is you might have a different conclusion about rejecting \(H_0\text{.}\) That is why you cannot just go \(\alpha\)-shopping till you get the decision you want. (If you want to do \(\alpha\)-shopping, you better do the p-Value as I explain below.) You must first set the \(\alpha\) value BEFORE you do the analysis. For instance, if you had set \(\alpha = 0.10\) in the two-tail case above, you would have rejected \(H_0\) while you were not able to reject \(H_0\) at \(\alpha=0.05\text{.}\) If you had set \(\alpha = 0.06\text{,}\) you wouldn’t have rejected \(H_0\) either. So, your conclusion does depend on you level of confidence you desire. Recall the level of confidence in complement of \(\alpha\text{,}\) i.e., \((1-\alpha)100\%\text{.}\)

    Subsection 1.12.2 Type I and TypeII Errors

    In the example above regarding whether the coin is fair or not, we analyzed the data collected from \(100\) tosses assuming the coin was fair (the null hypotheis, \(H_0\)), and found that at significance level \(\alpha\) we were unable to reject \(H_0\) since our data had \(59\) Heads. We also noticed that, had we got \(61\) Heads, which is entirely possible, we would have rejected \(H_0\text{.}\)
    This shows that just a variation in data collection, can lead us to the opposite conclusions, regardless of whether \(H_0\) happens to be true or not in reality. This makes two types of error possible in our decision.
    We say that we have made a Type I Error if we rejected the null hypothesis \(H_0\) in favor of \(H_1\) even though it shouldn’t have been. The probability of rejecting \(H_0\) assuming \(H_0\) is the correct distribution is what \(\alpha\) was. That is why \(\alpha\) is also called significance of the test.
    \begin{equation*} P(\text{Given Data and given }H_0\text{ as true, Reject } H_0) = \alpha. \end{equation*}
    Of course, the complement of this probability will be not to reject \(H_0\text{.}\)
    \begin{equation*} P(\text{Given Data and given }H_0\text{ as true, Do Not Reject } H_0) = 1 - \alpha. \end{equation*}
    Rejecting \(H_0\) when \(H_0\) is true will be an error, i.e., \(\alpha\) is a level of error we would need to avoid.
    A Type II Error occurs when we fail to reject \(H_0\) in favor of \(H_1\) when we should have rejected it. In the examples above, while \(H_0\) was a simple hypothesis:
    \begin{equation*} H_0 \sim \text{Bernoulli}(p_0), \end{equation*}
    the alternate hypothesis was a composite hypothesis, giving us distribution in terms of variable \(p\text{.}\)
    \begin{equation*} H_1 \sim \text{Bernoulli}(p),\quad p\ne 0. \end{equation*}
    To indicate the \(p\)-dependence, let’s write this hypothesis as
    \begin{equation*} H_1(p) \sim \text{Bernoulli}(p),\quad p\ne 0. \end{equation*}
    So, based on the choice of the value of \(p\text{,}\) we will get different probabilities of the event “Do not reject \(H_0\)”, i.e., of making an error of this type. This probability is denoted by \(\beta\text{,}\) which will depende on the value of \(p\) .
    \begin{equation*} \beta(p) = P(\text{Given Data and given }H_1(p)\text{ as true, Do Not Reject } H_0) \end{equation*}
    The compliment of this probability will be the probability that when \(H_1\) is true, we do reject \(H_0\text{,}\) as we should. This is called power of the test, usually denoted by letter \(P\text{.}\) Since, there are too many uses of letter \(P\text{,}\) we will just refrain from that practice here.
    \begin{equation*} \text{Power}(p) = 1 - \beta(p) = P(\text{Given Data and given }H_1(p)\text{ as true, Do Not Reject } H_0). \end{equation*}

    Remark 1.12.4. .

    To evaluate a statistical hypothesis for some parameter \(\theta\text{,}\) we define a critical region. This region is chosen to balance the probabilities of Type I and Type II errors, keeping both as low as feasible. However, reducing the Type I error probability (\(\alpha\)) typically increases the Type II error probability (\(\beta\)), as these are inversely related. In most practical scenarios, controlling \(\alpha\) is prioritized due to its importance in hypothesis testing.
    The process for selecting the critical region is as follows:
    • Specify a desired level for the Type I error probability, \(\alpha\text{.}\)
    • Identify a critical region that minimizes the Type II error probability, \(\beta\text{,}\) for a specific alternative hypothesis parameter, \(\theta\text{.}\)
    • If the resulting \(\beta(\theta)\) is unacceptably high, consider increasing \(\alpha\) to the maximum acceptable level.
    • If \(\beta(\theta)\) remains too large, increase the sample size \(n\) to improve the test’s power.
    A hypothesis test is deemed most powerful if it achieves the smallest possible \(\beta(\theta)\) for a given \(\alpha\text{.}\) The critical region of a most powerful test generally depends on the specific alternative parameter \(\theta\text{.}\)

    Subsection 1.12.3 The p Value Approach

    In the examples of rejection region approach, we saw that you failed to reject the null hypothesis if \(\alpha\) was too low. That is, there is a largest significance lavel \(\alpha\) at which we will be able to reject the null hypothsis, \(H_0\text{.}\) That \(\alpha\) is called the \(p\) value of the test.
    Traditional low \(p\) values such as \(p \lt 0.05\) or \(p \lt 0.01\) is considered statistically significant. Recall that we set the value of \(\alpha\) or \((1-\alpha)100%\) BEFORE we do the analysis. Here we would do the same and demand that the \(p\) value obtained from the data be less than \(\alpha\) for the test to be able to reject \(H_0\text{.}\)
    \begin{equation*} \text{Reject } H_0 \text{ if } p \text{ value} \lt \alpha. \end{equation*}
    Let’s look at the same example as the two-tail test presented above. Due to the misunderstanding of letter \(p\) being used for proportion in the example and the same letter used for \(p\) value, I will change the proportion symbol to \(\mu\) and the corresponding random variable to \(M\text{.}\) The hypotheses were
    \begin{align} \amp \text{Null hypothesis, } H_0: \quad \mu = 0.5 \equiv \mu_0\tag{1.12.6}\\ \amp \text{Alternate hypothesis, } H_1: \quad \mu \ne \mu_0\tag{1.12.7} \end{align}
    The data from \(n=100\) tosses had shown that \(\overline{\mu} = 0.59\text{.}\) We had introduced a standard normal variable to implement expectations assuming \(H_0\) were true.
    \begin{equation*} Z = \frac{\overline{M} - 0.5}{0.05} \sim \mathcal{N}(0, 1). \end{equation*}
    The information about \(H_0\) being true is in the choice of the numerical values \(0.5\) and \(0.05\text{.}\) The \(Z\) value corresponding to the data is obtained when we put the value fo the sample mean in this statistic.
    \begin{equation*} z = \frac{0.59 - 0.5}{0.05} = 1.8. \end{equation*}
    By inserting this in the CDF of the standard normal we find
    \begin{equation*} q = \Phi(1.8) = 0.964. \end{equation*}
    Because of the two-tail nature of the alternate hypothesis, this must correspond to \(1-\alpha_q/2\) since we would have the probability \(\alpha/2\) above it.
    \begin{equation*} 1-\alpha_q/2 = q = 0.964. \end{equation*}
    This gives \(\alpha_q = 0.072\text{.}\) That is, the \(p\) value will be \(0.072\text{.}\) This is too high \(p\) value for rejecting \(H_0\) since \(p = 0.072 \gt \alpha=0.05\equiv p\text{th}\text{,}\) the threshold value.
    Of course, you can, then, wrongly turn around, and say, let’s go back and set \(p_\text{th} = 0.1\) just so that you can use your data to reject \(H_0\) in favor of \(H_1\text{.}\) That is why, people insist that for rejecting some well-established fact embodied in the null hypothesis, your \(p\) value must be very very small. From an NIH paper:
     1 
    www.ncbi.nlm.nih.gov/books/NBK557421/
    “The best practice is to report all \(p\) values for all variables within a study design rather than only providing \(p\) values for variables with significant findings. Including all \(p\) values provides evidence for study validity and limits suspicion for selective reporting/data mining.”

    Subsection 1.12.4 Chi Square Goodness of Fit Test

    Suppose we are dealing with a \(k\)-class random variable or a real-valued variable which has been binned into \(k\) bins. Each new data point is placed into one of the \(k\) cartegories and the random variables \(X_i\) for the bins \(i=1,\cdots,k\) are the counts of samples in each class/bin. Such systems are governed by a multinomial distribution over the \(k\) random variables \((X_1, X_2, \cdots, X_k)\) which are constrained to add up to the total number \(n\) of data points.
    \begin{equation*} X_1 + X_2 + \cdots + X_k = n, \end{equation*}
    where each variable can rane between \(0\) and \(n\text{.}\)
    \begin{equation*} X_i \in [0,\ n]. \end{equation*}
    We call the collection of the \(k\) variables a multinomial random variable and will denote it in vector notation.
    \begin{equation*} \vec{X} = (X_1, X_2, \cdots, X_k). \end{equation*}
    Let \(p_i\) be the probability of next data to be in the \(i^\text{th}\) class (bin) and \(\vec{p} = (p_1, p_2, \cdots, p_k) \text{.}\) Then, we can write the distribution expected as
    \begin{equation*} \vec{X} \sim \text{Multinomial}\left( \vec{p}\right),\quad \sum_{i=1}^k\, p_i = 1. \end{equation*}
    By this, we mean the following probability mass function (PMF.)
    \begin{equation*} P(x_1, x_2, \cdots, x_k) = \frac{n!}{x_1!x_2!...x_k!}\,p_1^{x_1}\,p_2^{x_2}...\,p_k^{x_k},\quad \sum_{i=1}^k\,x_i = n. \end{equation*}
    See the discussion on multinomial distribution in the section on discrete probability distributions for the following results.
    \begin{equation*} \mathbb{E}[X_i] = n\,p_i,\quad \textrm{Var}(X_i) = np_i(1-p_i), \quad \textrm{Cov}(X_i, X_{j\ne i}) = -n p_i p_j. \end{equation*}
    Let the null hypothesis be
    \begin{equation*} H_0:\quad p_i = p_{0i}\, \text{ for } i = 1, 2, \cdots, k. \end{equation*}
    Let the alternate hypothesis be
    \begin{equation*} H_1:\quad p_i \ne p_{0i}\, \text{ for } i = 1, 2, \cdots, k. \end{equation*}
    The test is performed by Pearson test statistic \(Y\text{:}\)
    \begin{equation} Y = \sum_{i=1}^k\, \frac{\left( X_i - n\,p_{i0}\right)^2}{n\,p_{i0}}.\tag{1.12.8} \end{equation}
    For large values of \(n\text{,}\) it can be shown, although with some difficulty, that the Pearson test statistic \(Y\) has a \(\chi^2\) distribution with degrees of freedm equal to \(k-1\text{,}\) one less than the number of classes/bins.
    \begin{equation} Y \sim \chi^2_{k-1}.\tag{1.12.9} \end{equation}
    Thus, to find the region for rejecting \(H_0\) with significance level \(\\alpha\text{,}\) we just need to find the rejection region above \(q\text{.}\) The value of \(q\) will be such that following probability statement is true.
    \begin{equation*} P\left(\text{Reject }H_0 \text{ if } Y \gt q \mid H_0\right) = \alpha. \end{equation*}
    Using the inverse CDF of \(\chi^2_{k-1}\text{,}\) this will be
    \begin{equation*} q = F^{-1}_{k-1}(1-\alpha). \end{equation*}
    We use symbol \(\chi^2_{k-1,\ 1-\alpha}\) for the value rather than \(q\text{.}\)

    Example 1.12.5. Is the Die a Fair Die?

    Suppose we roll a six-sided die \(600\) times and find the following numbers of faces 1 through 6: \(n_i = (80, 120, 100, 150, 130, 120)\text{.}\) Is the die fair at significance level \(0.05\text{?}\)
    By a fair die, we mean each side should have the proportion:
    \begin{equation*} p_{i0} = \frac{1}{6},\quad H_0:\ p_i = p_{i0}.,\quad H_1: p_i\ne 0. \end{equation*}
    With \(n=1000\text{,}\) for every side, we get \(np_{i0} = 600/6 = 100 \text{.}\) Now, we calculate the Pearson test statistic:
    \begin{align*} Y \amp = \frac{ (80-100)^2 }{100} + \frac{ (120-100)^2 }{100} + 0 + \frac{ (150-100)^2 }{100} \\ \amp \quad + \frac{ (130-100)^2 }{100} + \frac{ (120-100)^2 }{100}\\ \amp = 4 + 4 + 0 + 25 + 9 + 4 = 46 \end{align*}
    Now, we compare this to the critical value at the significance level which comes from the inverse \(\chi^2_{6-1}\) distribution.
    \begin{equation*} \chi^{2}_{5,\, 0.95} = 11.07. \end{equation*}
    Since \(Y \gt \chi^{2}_{5,\, 0.95} \text{,}\) we can reject the fair die hypothesis \(H_0\text{.}\)

    Example 1.12.6. Testing a Distribution.

    Suppose we want to test if the random number generator that generates real number in the interval \((0, 1)\) is uniformly distributed at significance \(\alpha = 0.02\) . Now, we do not have classes like we did in the six-sided die. So, we create bins. Let us create bins of equal widths of \(0.1\) and whenever we get a random number, we will place it in one of the \(10\) bins.
    Suppose, we obtain \(1000\) samples tht result in the following frequencies: \(n_i = (85, 88, 110, 105, 120, 112, 102, 80, 112, 86)\text{.}\) Our \(H_0\) hypothesis is
    \begin{equation*} p_{i0} = \frac{1}{10}. \end{equation*}
    This will give \(n\,p_{i0} = 1000/10 = 100\text{.}\) Now, we calculate the Pearson test statistic.
    \begin{equation*} Y = \sum_{i=1}^{10} \frac{ (n_i - 100 )^2 }{100} = 17.82. \end{equation*}
    The critical value here is
    \begin{equation*} \chi^2_{9,\,0.98} = 19.68. \end{equation*}
    Since \(Y \lt \chi^2_{9,\,0.98}\text{,}\) we do not reject \(H_0\text{,}\) i.e., the claim that the random number generator that gave us the values we observed is uniform at the significance level \(0.02\text{.}\)
