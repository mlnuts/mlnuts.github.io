    Section 2.1 Statistical Decision Theory

    Statistics is the application of probability theory to real-world problems. Basically, two types of problems are handled by using statitics: (1) the estiamtion of parameters of a statistical model, and (2) predictions of future outcomes assuming the underlying probabilistic model is fully known. Both of these are necessary to make an optimized decision in an uncertain environment.
    Optimization is done by minimizing a loss function, or, alternately, maximizing a reward function. The choice of loss function is critical since that provides the constraint under which decisions will be optimal. We will see that the loss function for discrete random variables and continuous random variables will be different.
    As an illustration of the optimization process let us consider two scalar random variables \(X\) and \(Y\text{.}\) Suppose, we have made \(n\) independent and identical observations of \((X,Y)\) pairs:
    \begin{equation*} \text{DATASET: }\mathcal{D} = \{ (x^{(1)},y^{(1)}), (x^{(2)},y^{(2)}), \cdots, (x^{(n)},y^{(n)}) \} \end{equation*}
    We will use superscipts to indicate data instances, i.e., data points, and reserve the subscript indices for components of vector, matrix or tensor-like variables. Suppose the experiment from which the data was collected can be modeled by some statistical model, given by a joint distribution function \(F_{XY}(x,y; \theta)\) or the corresponding joint probability density \(\rho_{XY}(x,y;\theta)\) (or PMF in case of discrete variables) with parameters \(\theta\text{.}\)
    We want to predict \(y^{n+1}\) that goes with the new \(x^{n+1}\) assuming the relation between \(x\) and \(y\) are statistical. That is, we seek a function \(f(X)\) which will give the “best” \(y^{n+1}\) from \(f(x^{n+1})\text{.}\) We will denote this optimal function by placing a hat on the symbol as in \(\hat{f}\text{.}\) All we then we need to predict \(y^{n+1}\) that goes with \(x^{n+1}\) is
    \begin{equation*} y^{n+1} = \hat{f}(x^{n+1}). \end{equation*}
    What is the meaning of “best” function here? We say that there is a loss function \(\mathcal{L}(X, Y=f(X))\) that will be minimized if we chose the “right” \(f(X)\text{.}\)
    \begin{equation*} \text{Loss Function: } \left.\mathcal{L}(X, Y)\right|_{Y=f(X)} \equiv \mathcal{L}(Y, f(X)). \end{equation*}
    You would think that the optimal function would be obtained by
    \begin{equation*} \hat f = \min\limits_{f}\ \mathcal{L}(Y, f(X))\quad (\text{INCORRECT!}) \end{equation*}
    This equation is minimizing a function of random variables \(X\) and \(f(X)\text{.}\) What we should be doing is to minimize its expectation value. Since we are in a joint distribution of \((X,Y)\text{,}\) this optimization process should be
    \begin{equation*} \hat f = \min\limits_{f}\ \mathbb{E}_{XY}[\mathcal{L}(Y, f(X))]\quad (\text{CORRECT!}) \end{equation*}
    It helps to separate out the \(y\) and \(x\) parts if we write the PDF of a joint distribution in terns of a conditional and a marginal distriution.
    \begin{equation*} \rho_{XY}(x,y) = \rho_{Y\mid x}(y\mid x)\,\rho_X(x). \end{equation*}
    Using this and integrating over \(y\) inside the \(x\) integral
    \begin{equation*} \hat f = \min\limits_{f}\ \int\ dx\ \rho_X(x) \,\left[ \int\, dy\, \rho_{Y\mid X}\ \mathcal{L}(y, f(x)) \right]. \end{equation*}
    Since \((\rho_X(x)\,dx)\) is \(P(x \le X \le x + dx) \gt 0\text{,}\) the minimization of the quantities just inside the square brackets \([\cdots]\) is enough to find the optimal \(f\text{.}\) Hence, you don’t need the full joint probability density, just the conditional density is enough.
    \begin{equation} \hat f = \min\limits_{f}\ \int\, dy\, \rho_{Y\mid X}\ \mathcal{L}(Y, f(X)).\tag{2.1.1} \end{equation}
    The supervised learning algorithms of Machine Learning are all based on this equation. Various algorithms try to “learn” the function \(\hat{f}\) from the data and use them to make predictions on new datapoints. In this section, I will illustrate the application of this formula to a regression task. In the next section, we will discuss a binary classification task.

    Subsection 2.1.1 Regression

    A common loss function for regression tasks for predicting continuous variable \(Y\) is the squared error.
    \begin{equation*} \mathcal{L}( X, Y) = (Y - f(X))^2. \end{equation*}
    For arbitrary point \((x,y)\) in the random variable space of \((X,Y)\text{,}\) the error will be
    \begin{equation*} \mathcal{l} = (y - f(x))^2. \end{equation*}
    Therefore, the equation for optimal \(f\) becomes
    \begin{equation*} \hat f = \min\limits_{f}\ \int\, dy\, (y - f(x))^2\, \rho_{Y\mid X}(y\mid x). \end{equation*}
    Setting the functional derivative of the integral on the right side to zero shoudl give us the extremum function, say \(\tilde{f}\text{.}\)
    \begin{equation*} \left[\frac{\delta}{\delta f}\,\int\, dy\ (y - f(x))^2\right]_{f = \tilde{f}}\, \rho_{Y\mid X}(y\mid x) = 0 \end{equation*}
    This will give us (Think of a regular partial derivative with \(f\) as an independent variable.)
    \begin{align*} \int\, dy\, y \amp \, \rho_{Y\mid X}(y\mid x)= \int\, dy\, \tilde{f}(x)\, \rho_{Y\mid X}(y\mid x).\\ \amp = \tilde{f}(x)\,\int\, dy\, \rho_{Y\mid X}(y\mid x) \quad (\text{since integraing over }y \text{ keeping } x \text{ fixed.})\\ \amp = \tilde{f}(x)\quad (\text{ since the PDF is normalized}) \end{align*}
    That is the extremum of the squared loss occurs at \tilde{f}.
    \begin{equation*} \tilde{f} = \int\, dy\, y\, \rho_{Y\mid X}(y\mid x) = \mathbb{E}_{Y\mid X}[Y]. \end{equation*}
    Is it mimimum? To show that it is a minimum, try finding the second derivative and use the expectation symbol to hide away the integration.
    \begin{equation*} \frac{\delta }{\delta\, f}\left( \frac{\delta }{\delta\, f}\, \mathbb{E}_{Y \mid X}[\mathcal{L}(Y, f(X))] \right) = 2 \gt 0. \end{equation*}
    That means the extremum value is actualy a minimum. Thus, the optimal funtion that minimizes the squared error is the one that maps \(x\) to the mean value of \(Y\) in the conditional probability \(\rho_{Y\mid X}\text{.}\) Hence, in terms of the random variables, the optimal function is
    \begin{equation} \hat{f}(X) = \mathbb{E}_{Y \mid X}[Y] = \int\ dy\ y\ \rho_{Y\mid X}(y\mid x).\tag{2.1.2} \end{equation}
    This is a theretical result of the prediction function. To apply this result to obtain \(y^{n+1}\) that gies with \(x^{n+1}\text{,}\) further assumptions are made. For instance, as we will see below in k-NN algorithm, each datapoint in the dataset \(\mathcal{D}\) is given probaility \(1/k\text{,}\) where \(k\) is the number of nearest neighbors of \(x^{n+1}\) in the training dataset.
    In some approached, we invoke a functional form of \(f\text{,}\) e.g., a linear function of \(X\text{,}\) then you can use the points in the dataset \(\mathcal{D}\) to estimate parameters of that function which you can then use to make prediction for the new point \(x^{n+1}\text{.}\)

    Subsection 2.1.2 The kNN Method

    A straightforward way of implementing the result in Eq. (2.1.2) for making prediction of \(y^{n+1}\) for a new point with \(X = x^{n+1}\) is to average the \(Y\) values of points in the dataset \(\mathcal{D} = \{ (x^{(1)},y^{(1)}), (x^{(2)},y^{(2)}), \cdots, (x^{(n)},y^{(n)}) \}\) closest to \(X = x^{n+1}\) their \(X\)-distances.
    The simplest is, of course, to just look at the nearest neightbor, say “distance” to \(x^{a}\) from \(x^{n+1}\) is smallest, assuming unique for simplicity, then, you would say that that \(y^{n+1}\) is same as \(y^{a}\text{.}\)
    If you have degenracy, say, distances to \(x^{a}\) and \(x^{b}\) from \(x^{n+1}\) are smallest and equal. Then, for \(y^{n+1}\text{,}\) we would just averate the \(y\)’s.
    \begin{equation*} y^{n+1} = \frac{y^{a} + y^{b} }{2}. \end{equation*}
    We might want to extend the averaging to more than the nearest average. That’s where \(k-NN\) (\(k\) Nearest Neighbors) algorithm comes in. You go to the location \(x^{n+1}\) and expand out and count upto \(k\) closest neighbors.. Say, indices for them are : \(i_1, i_2, \cdots, i_k\text{.}\) Then, to predict \(y^{k+1}\) you would average their \(y\)’s, which is essentially approximating \(\rho_{Y\mid X} = 1/k\) and truning the integral into a sum.
    \begin{equation*} y^{n+1} = \frac{1}{k}\left( y^{i_1} + y^{i_2} +\cdots + y^{i_k} \right). \end{equation*}
    For scalar functions \(X\text{,}\) the k-NN method works quite well if you have sufficiently dense coverage of the \((X,Y)\) by the data, but for vector variables, such as \(\vec{X}\) with several components, say \(d\)-coponents, the number of neighbors grows exponetially with \(d\text{,}\) and the method become impractical. You can prove a theoretical result that shows that at some point it will become impossible since almost all datapoints will be included in any search and hence you will be predicting same \(y\) for every \(x^{n+1}\text{.}\) This result goes by the ominous phrase “the curse of dimensionality”.

    Subsection 2.1.3 The Simple Linear Regresson

    For \(X\) a scalar variable, a linear dependency of \(Y\) on \(X\) will be
    \begin{equation*} Y = f(X) = \beta_0 + \beta_1\,X, \end{equation*}
    where \(\beta_0\) is the \(y\text{-intercept}\) and \(\beta_1\) the slope. The task is to find the optimal values of \(\beta_0\) and \(\beta_1\) that minimizes the squared error, where we now include a factor \(1/2\) for cancling out a factor \(2\) that results when you take derivatives.
    \begin{equation*} \mathcal{L}(Y, f(X)) = \frac{1}{2} (Y - \beta_0 - \beta_1\,X)^2. \end{equation*}
    Assuming the the dataset \(\mathcal{D}\) is representative of the entire \(\rho_{Y\mid X}(y\mid x)\text{,}\) we find approximation of the \(\mathbb{E}[L]\) by setting
    \begin{equation*} \rho_{Y\mid X}(y^{(i)}\mid x^{(i)}) = \frac{1}{n}, \end{equation*}
    and repacing the integration by the sum. Let’s call this expectation value of \(\mathcal{L}\) by \(\mathcal{L}_D\)
    \begin{equation*} \mathcal{L}_D = \frac{1}{2n}\sum_{i=1}^{n}\,\left(y^{(i)} - \beta_0 - \beta_1\,x^{(i)}\right)^2. \end{equation*}
    Now, to find the optimal function \(f\text{,}\) here the optimal parameters \(\beta_0\) and \(\beta_1\text{,}\) we just have to take partials with each and set to zero.
    \begin{align*} \amp \frac{\partial \mathcal{L}_D}{\partial \beta_0} = 0\\ \amp \frac{\partial \mathcal{L}_D}{\partial \beta_1} = 0 \end{align*}
    These result in two linear equations in \(\beta_0\) and \(\beta_1\) which are easily solved. We denote the solutions by \(\hat{\beta}_0\) and \(\hat{\beta}_1\text{.}\) You will find that the following sums help in doing the algebra.
    \begin{equation*} \bar{x} = \frac{1}{n}\,\sum_{i=1}^n\,x^{(i)},\quad \bar{y} = \frac{1}{n}\,\sum_{i=1}^n\,y^{(i)}. \end{equation*}
    After algebra that you should do out, you will find the following expressions for the optimal parameters.
    \begin{align*} \amp \hat{\beta}_1 = \frac{ \sum_{i=1}^n\, ( x^{(i)} - \bar x )( y^{(i)} - \bar y ) }{ \sum_{i=1}^n\, \left( x^{(i)} - \bar{x} \right)^2 }\\ \amp \hat{\beta}_0 = \bar{y} - \beta_1 \bar{x} \end{align*}

    Example 2.1.1.

    Figure 2.1.2 shows a simple linear regression on a dataset \(\mathcal{D}\) consisting of \(100\) datapoints generated by adding noise to a linear deterministic function by
    \begin{equation*} Y = f(X) = 1.0 + 2.0 * X + \epsilon, \end{equation*}
    where
    \begin{equation*} \epsilon \sim \mathcal{N}(0,1). \end{equation*}
    Here, we have chosen known values of \(\beta_0 = 1.0\) and \(\beta_1 = 2.0\) to generate the data and want to know how well the simple linear regression produces estimates of these parameters.
    The simple linear regression using \(100\) datapoints gave the predicting funtion to be
    \begin{equation*} \hat{Y} = \hat{f}(X) = \hat{\beta}_0 + \hat{\beta}_1\, X, \end{equation*}
    with
    \begin{equation*} \hat{\beta}_0 = 0.83,\quad \hat{\beta}_1 = 2.01. \end{equation*}
    Compare them to the “true” values:
    \begin{equation*} \beta_0 = 1.0,\quad \beta = 2.0. \end{equation*}
    From the data, we appear to get a better estimate for the slope than that of the intercept.
    Note that since the dataset, coming from a random sampling process, is a random variable. Therefore, the estimates \(\hat{\beta}_0\) and \(\hat{\beta}_1\) deduced from using \(\mathcal{D}\) are also random variables with their own distributions.
    \begin{equation*} \hat{\beta}_0 \sim \rho(\hat{\beta}_0),\quad \hat{\beta}_1 \sim \rho(\hat{\beta}_1). \end{equation*}
    The estimates we gave above are just estimates of their mean values. And, of course, you can do an entire analysis of the significance level of these estimates. While important in statistics books, they will be largely ignored in the Machine Learning work. We take the view that the estimates of the parameters give us the best we can do.
    The figure was generated by the following Python code.
    import numpy as np
import matplotlib.pyplot as plt

# Sample dataset
np.random.seed(42) # for reproducibility
X = np.linspace(0, 10, 100)
Y = 1.0+ 2.0 * X  + np.random.normal(0, 1, 100)  # Y = 2X + 1 + noise

# Calculate means
x_bar = np.mean(X)
y_bar = np.mean(Y)

# Calculate beta_1 (slope)
numerator = np.sum((X - x_bar) * (Y - y_bar))
denominator = np.sum((X - x_bar) ** 2)
beta_1 = numerator / denominator

# Calculate beta_0 (intercept)
beta_0 = y_bar - beta_1 * x_bar

# Print results
print(f"Estimated beta_0 (intercept): {beta_0:.2f}")
print(f"Estimated beta_1 (slope): {beta_1:.2f}")

# Plot the data and regression line
plt.scatter(X, Y, facecolors='none', edgecolors='blue', color='blue', label='Data points')
plt.plot(X, beta_0 + beta_1 * X, color='red', label='Regression line')
plt.xlabel('X')
plt.ylabel('Y')
plt.title('Simple Linear Regression Example')
plt.legend()
plt.grid(True)
plt.show()
