    Section 2.5 Multi-Class Classification

    In binary classification, the target \(Y\) could be one of two categories — 0/1, yes/no, true/false, up/down, etc. In multiclass classification tasks, we are asked to predict one most likely class from three or more discrete target classes. This is to be distinguished from a multilabel prediction task, where you would predict two or more most likely classes from several posible classes.
    The extension from the binary classification task is straightforward, but at times can be confusing. We work out the details for a \(K\)-class problem.
    First, we will discuss the loss function for the \(K\)-class problem. Just like the binary classification problem, we model the conditional probabilities directly. We will see that a softmax function models the probabilities of the \(K\) classes given \(X\) such that their sum properly equals \(1\text{.}\) Once, we have predictions of the probabilities \(p_1,\ p_2, \cdots, p_K\text{,}\) we predict the class by simply finding the class that has the highest among them.
    \begin{equation*} \text{Predict most likely class is the index of }\ \max( p_1,\ p_2, \cdots, p_K ). \end{equation*}

    Subsection 2.5.1 Loss Function of Multiclass Classification

    First, let us recall the binary classification for an \(r\)-dimensional feature vector \(\vec X = (X_1, \cdots, X_r)\text{.}\) There is one variable \(Y\) which is encoded as \(Y \in \{0,1\}\text{,}\) with \(Y=1\) denoting class \(1\) and \(Y=0\) denoting class \(0\text{.}\) The conditional probabilities of the two classes given \(X\) are
    \begin{equation*} p_1 = P(Y=1\mid X),\ \ p_0 = P(Y=0\mid X),\ \ \text{ with } p_1 + p_0 = 1. \end{equation*}
    We model the conditional probability \(p_1(X;\theta) = P(Y=1\mid X;\theta)\text{.}\) In the logistic regression algorithm, we further assume a mathematical form of this conditional probability:
    \begin{equation*} p_1(X; \theta) = \sigma(z),\ \ z = w_0 + w_1 X_1 + w_2 X_2 + \cdots + w_r X_r, \end{equation*}
    where the sigmoid function is
    \begin{equation*} \sigma(z) = \frac{1}{1 + e^{-z}}. \end{equation*}
    The quantity \(z\) is called the score. The loss function for optimizing the parameters \(w_i\)’s is written as
    \begin{equation*} \mathcal{L}_\text{binary} = -\left[Y\, \log (p_1(X; \theta)) + (1 - Y)\,\log (1 - p_1(X; \theta)) \right]. \end{equation*}
    When \(Y=1\text{,}\) you only have the first term with log of the probability corresponding to class \(1\text{,}\) and when \(Y=0\text{,}\) you only have the second term, whose argument to the log is the probability for class \(0\text{.}\) Let us introduce an indicator/kronecker delta variable to write this expression more succinctly.
    \begin{equation} \delta_{y,c} = \begin{cases} 1 \amp\ \text{ if } y=c\\ 0 \amp\ \text{ if } y\ne c \end{cases}\tag{2.5.1} \end{equation}
    Then, the loss function is a sum over the two classes.
    \begin{equation} \mathcal{L}_\text{binary} = - \sum_{c=0}^1\, \delta_{Y,c}\,\log p_c(X; \theta)\tag{2.5.2} \end{equation}
    For instance, if you have a datapoint \((\vec{x}^{(i)}, y=0)\text{,}\) i.e., this datapoint belongs to class \(0\text{,}\) then the value of this loss function will be
    \begin{align*} \mathcal{L}_\text{binary} \amp = - \sum_{c=0}^1\, \delta_{0,c}\,\log (p_c(\vec{x}^{(i)}; \theta)) \\ \amp = - \delta_{0,0}\,\log( p_0(\vec{x}^{(i)}; \theta)) - \delta_{0,1}\,\log( p_1(\vec{x}^{(i)}; \theta))\\ \amp = - 1 \times \log( p_0(\vec{x}^{(i)}; \theta) ) - 0\times \log( p_1(\vec{x}^{(i)}; \theta)) \\ \amp = - \log( p_0(\vec{x}^{(i)}; \theta) ) = - \log( 1 - p_1(\vec{x}^{(i)}; \theta) ) \end{align*}
    The binary loss formula in Eq. (2.5.2) can be clearly generalized to a \(K\)-class classification problem, by just summing over \(K\) classes, provided the probabilities add up to \(1\text{.}\)
    \begin{equation} \mathcal{L}_K = - \sum_{c=1}^K\, \delta_{Y,c}\,\log p_c(X; \theta),\ \ \text{ with }\ \ \sum_{c=1}^K\, p_c(X; \theta) = 1.\tag{2.5.3} \end{equation}
    So, how should we model \(p_c(X; \theta)\text{?}\) The sigmoid representation of \(p_1\) for the binary case gives a clue if we rewrite the sigmoid a little differently:
    \begin{equation*} p_1 = \frac{1}{1 + e^{-z}} = \frac{e^z}{e^z + 1}. \end{equation*}
    That means
    \begin{equation*} p_0 = 1 - p_1 = \frac{1}{e^z + 1}. \end{equation*}
    Let’s denote the denominator by the letter \(Z\) and then
    \begin{equation*} p_1 = \frac{e^z}{Z},\ \ p_0 = \frac{1}{Z}, \end{equation*}
    which satisfies the probability sum requirement automatically. This suggests that we should write similar formulas for a \(K\)-class task. Since we have more than two classes, we will write scores for each with an index for the class:
    \begin{align*} \amp p_1 = \frac{e^{Z_1}}{Z},\ \ p_2 = \frac{e^{Z_2}}{Z},\ \ \cdots,\ \ p_K = \frac{e^{Z_K}}{Z} \end{align*}
    with
    \begin{equation*} Z = e^{Z_1} + e^{Z_2} + \cdots + e^{Z_K}. \end{equation*}
    This representation of the probabilities is called the softmax function over the \(K\) classes. Explicitly,
    \begin{equation*} \text{softmax}(Z_c) = \frac{e^{Z_c}}{\sum_{j=1}^K e^{Z_j}}. \end{equation*}
    Using the softmax function, the \(K\)-class loss in Eq. (2.5.3) can be written compactly as
    \begin{equation} \mathcal{L}_K = - \sum_{c=1}^K\, \delta_{Y,c}\,\log \text{softmax}(Z_c) = - \log \text{softmax}(Z_Y),\tag{2.5.4} \end{equation}
    where \(Z_Y\) is the score for class \(Y\) coming from the input vector \(\vec X\) and the parameters \(w_{Y,i}\)’s:
    \begin{equation*} Z_Y = w_{Y,0} + \sum_{i=1}^r\, w_{Y,i}\,X_i. \end{equation*}
    We find the optimal values of parameters by seeking the minimum of the expected value of the loss over the training dataset:
    \begin{equation*} \mathcal{D} = \{ (\vec{x}^{(i)}, y^{(i)} ) \mid i=1, 2, \cdots, n \}. \end{equation*}
    For brevity in writing, let us denote the class corresponding to the class \(y^{(i)}\) in the \(i^\text{th}\) datapoint by \(c_y\text{.}\)
    \begin{equation*} c_y \equiv y^{(i)} \end{equation*}
    For each datapoint and the parameters for its true class \(c_y = y^{(i)}\text{,}\) we will have a score:
    \begin{equation*} Z_{c_y}^{(i)} = w_{c_y,0} + \sum_{j=1}^r\, w_{c_y,j}\,X_j^{(i)}, \end{equation*}
    which we can use in the loss function. Thus, we optimize the following loss evaluated from all the datapoints in the dataset:
    \begin{align*} \mathcal{L}_D \amp = - \frac{1}{n} \sum_{i=1}^n\,\left[\sum_{c=1}^K\, \delta_{y^{(i)},c}\,\log \text{softmax}(Z_c)\right] = - \frac{1}{n} \sum_{i=1}^n\, \log \text{softmax}\left(Z_{c_y}^{(i)}\right) \end{align*}
    From the indices that label the parameters, it appears that we have \((r+1)K\) parameters, but since probabilities over all \(K\) classes must add up to \(1\text{,}\) only \((r+1)(K-1)\) parameters are independent. This is included in the softmax function since shifting all scores by the same amount does not change the softmax output.

    Subsection 2.5.2 Derivative of Multiclass Loss Function

    Taking the derivative of \(\mathcal{L}_D\) with respect to parameters \(w_{c, j}\) with \(c = 1, 2, \cdots, K\) (classes) and \(j = 0, 1, 2, \cdots, r\) (bias part and \(r\) components of feature vector \(\vec X\)) will proceed the same way for each datapoint. So, it’s better to drop the index \((i)\) from the notation when taking derivatives and restore them in the final results.
    \begin{align*} \amp \text{Simplified Notation:}\\ \amp \qquad x_j \quad \text{ for }\quad x_j^{(i)} \\ \amp \qquad y \quad \text{ for }\quad y^{(i)} \\ \amp \qquad S \quad \text{ for }\quad \text{softmax} \end{align*}
    Then, the required derivatives of one term of the empirical loss function without the \(1/n\) factor, to be denoted by \(\mathcal{l}_D\text{,}\) will be
    \begin{align*} \frac{\partial \mathcal{l}_D}{\partial w_{c, j}} \amp = - \sum_{c'=1}^K\, \delta_{y,c'}\, \frac{\partial \log S(Z_{c'})}{ \partial Z_c'} \frac{\partial Z_c'}{\partial w_{c, j}} \\ \amp c \in \{1, 2, \cdots K\},\quad j \in \{0, 1, 2, \cdots, r \}. \end{align*}
    where the sum on classes is using a dummy index \(c'\) rather than \(c\text{,}\) which is the index of a particular parameter with respect to which we seek the derivative. Now, the components on the right side can be worked out individually.
    \begin{align*} \frac{\partial \log S(Z_c')}{ \partial Z_c'} \amp = \frac{\partial }{ \partial Z_c'}\log \left( \frac{e^{Z_{c'}}}{\sum_{l=1}^K e^{Z_l}} \right) = \frac{\partial }{ \partial Z_c'}\left( Z_c' - \log ( \sum_{l=1}^K e^{Z_l} ) \right)\\ \amp = 1 - \frac{\sum_{l=1}^K e^{Z_l}\delta_{c',l}}{\sum_{l=1}^K e^{Z_l}} = 1 - \frac{ e^{Z_{c'}}}{\sum_{l=1}^K e^{Z_l}} = 1 - S(Z_{c'})\\ \frac{\partial Z_c'}{\partial w_{c, j}} \amp = \frac{\partial }{\partial w_{c, j}} \left( w_{c',0} + \sum_{l=1}^r\,w_{c',l}x_l \right)\\ \amp= \begin{cases} \delta_{cc'} \amp \text{if } j = 0\\ \delta_{cc'}x_j \amp \text{if } j \ne 0 \end{cases} \end{align*}
    Thus, we have the following derivatives for the empirical loss function with respect to the parameters.
    \begin{align*} \frac{\partial \mathcal{L}_D}{\partial w_{c, 0}}\amp = \frac{1}{n} \sum_{i=1}^{n}\left( S(Z_{y^{(i)}}) - 1 \right) \\ \frac{\partial \mathcal{L}_D}{\partial w_{c, j\ne 0}}\amp = \frac{1}{n} \sum_{i=1}^{n}\left( S(Z_{y^{(i)}}) - 1 \right)\, x_j^{(i)} \end{align*}
    These derivatives are then used in the gradient descent algorithm to find their optimum values as has been illustrated before.

    Example 2.5.1. The Iris Classification Problem.

    The Iris dataset is one of the most famous datasets in machine learning. Collected by the botanist Ronald A. Fisher in 1936, it contains measurements of 150 iris flowers from three different species:
    • Iris setosa
    • Iris versicolor
    • Iris virginica
    Each flower is described by four features:
    1. Sepal length
    2. Sepal width
    3. Petal length
    4. Petal width
    Sepals are the outer green leaf-like structures that protect the flower bud. Petals are the colorful parts that attract pollinators.
    The task is to use these numerical features to predict the species of the iris. This makes it a classic multiclass classification problem with:
    1. Input matrix X of shape (n_samples, 4)
    2. Target labels y with 3 possible categories (Setosa, Versicolor, Virginica)
    Because the Iris dataset is small, structured, and easy to visualize, it is often used to demonstrate the fundamentals of machine learning models.
    In this project, we implement multiclass logistic regression (softmax regression) from scratch using NumPy. We optimize the model using gradient descent and evaluate it on the Iris dataset.

    import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score
# -------------------------
# 1. Load Iris dataset
# -------------------------
X, y = load_iris(return_X_y=True)
num_classes = len(np.unique(y))  # 3 classes
# Normalize features
scaler = StandardScaler()
X = scaler.fit_transform(X)
# One-hot encode targets
y_onehot = np.eye(num_classes)[y]
# Train/test split
X_train, X_test, y_train, y_test = train_test_split(
    X, y_onehot, test_size=0.2, random_state=42
)
# -------------------------
# 2. Softmax + loss
# -------------------------
def softmax(logits):
    exp_logits = np.exp(logits - np.max(logits, axis=1, keepdims=True))
    return exp_logits / np.sum(exp_logits, axis=1, keepdims=True)
def cross_entropy_loss(y_true, y_pred):
    eps = 1e-15
    return -np.mean(np.sum(y_true * np.log(y_pred + eps), axis=1))
# -------------------------
# 3. Training with gradient descent
# -------------------------
def train_softmax_classification(X, y, num_classes, lr=0.1, epochs=500):
    n_samples, n_features = X.shape
    W = np.zeros((n_features, num_classes))
    b = np.zeros((1, num_classes))
    losses = []
    for epoch in range(epochs):
        # Forward pass
        logits = X @ W + b
        y_pred = softmax(logits)
        # Loss
        loss = cross_entropy_loss(y, y_pred)
        losses.append(loss)
        # Gradients
        grad_W = (X.T @ (y_pred - y)) / n_samples
        grad_b = np.mean(y_pred - y, axis=0, keepdims=True)
        # Update
        W -= lr * grad_W
        b -= lr * grad_b
        if (epoch+1) % 100 == 0:
            print(f"Epoch {epoch+1}, Loss: {loss:.4f}")
    return W, b, losses
# -------------------------
# 4. Train model
# -------------------------
W, b, losses = train_softmax_classification(X_train, y_train, num_classes, lr=0.1, epochs=1000)
# -------------------------
# 5. Predictions \amp; Accuracy
# -------------------------
def predict(X, W, b):
    logits = X @ W + b
    return np.argmax(softmax(logits), axis=1)
y_pred_train = predict(X_train, W, b)
y_pred_test = predict(X_test, W, b)
train_acc = accuracy_score(np.argmax(y_train, axis=1), y_pred_train)
test_acc = accuracy_score(np.argmax(y_test, axis=1), y_pred_test)
print(f"Training accuracy: {train_acc:.4f}")
print(f"Test accuracy: {test_acc:.4f}")
# -------------------------
# 6. Plot loss curve
# -------------------------
plt.figure(figsize=(6,4))
plt.plot(losses, label="Training Loss")
plt.xlabel("Epochs")
plt.ylabel("Cross-Entropy Loss")
plt.title("Loss Curve (Iris Softmax Regression)")
plt.legend()
plt.show()

    Example 2.5.2. Predicting Hand Written Digits.

    In this section, we will build a multiclass logistic regression model (also known as softmax regression) from scratch in Python. Instead of relying on pre-built machine learning libraries, we will implement the mathematics ourselves using NumPy and optimize the parameters with gradient descent.
    For data, we will use the classic MNIST handwritten digits dataset, a benchmark in machine learning that contains 70,000 grayscale images of digits 0 through 9. Each image is a 28×28 pixel grid, which we flatten into a feature vector of dimension 784. The target labels are integers from 0 to 9. To simplify the task and keep training efficient, we will restrict the dataset to only the first five digits (0–4). This gives us a five-class classification problem with inputs \(X ∈ ℝ^{n×784}\) and one-hot encoded outputs \(Y ∈ ℝ^{n×5}\text{,}\) where \(n\) is the number of samples.
    This exercise illustrates how the softmax function converts raw model scores into probabilities across multiple classes and how cross-entropy loss guides learning. It also demonstrates the practical use of MNIST as a stepping stone toward understanding more complex models like neural networks.

def train_softmax_classification(X, y, num_classes, lr=0.1, epochs=300):

        losses.append(loss)
        grad_W = (X.T @ (y_pred - y)) / n_samples
        grad_b = np.mean(y_pred - y, axis=0, keepdims=True)
        W -= lr * grad_W
        b -= lr * grad_b
        if (epoch+1) % 50 == 0:
            print(f"Epoch {epoch+1}, Loss: {loss:.4f}")
    return W, b, losses
# -------------------------
# 4. Train
# -------------------------
W, b, losses = train_softmax_classification(X_train, y_train_oh, 
num_classes, lr=0.5, epochs=500)

    logits = X @ W + b
