    Section 2.6 Bayesian Methods

    In supervised learning, we often model the conditional probability \(P(Y \mid X)\text{.}\) This naturally appears in Bayes’ theorem as the “posterior probability”. Recall the identity:
    \begin{equation*} P(Y \mid X) P(X) = P(X \mid Y) P(Y). \end{equation*}
    Equivalently, Bayes’ theorem can be written as
    \begin{equation*} P(Y \mid X) = \frac{P(X \mid Y) P(Y)}{P(X)}. \end{equation*}
    When we use Bayes’ theorem to model conditional probabilities and guide decision-making, the resulting approaches are called Bayesian methods.
    For comparing possible outcomes \(Y=y_i\) given the same \(X\text{,}\) the denominator \(P(X)\) cancels out, so we only need relative probabilities:
    \begin{equation*} P(Y \mid X) \propto P(X \mid Y) P(Y) \equiv \tilde P(Y \mid X). \end{equation*}
    Let us call the right side un-normalized probabilities \(\tilde P(Y \mid X)\text{.}\) Then, to make decision of which outcome is more likely, we just compare their unnormalized probabilities rather than the actual probabilities since the two woudl give the same answer.
    \begin{equation*} P(Y=y_i \mid X) \gt P(Y=y_j \mid X) \iff \tilde P(Y=y_i \mid X) \gt \tilde P(Y=y_j \mid X) \end{equation*}
    Therefore, we choose \(Y=y_i \) over \(Y=y_j\) by
    \begin{equation*} \text{if } \tilde P(Y=y_i \mid X) \gt \tilde P(Y=y_j \mid X) \text{ the, pick }y_i\text{ over }y_j. \end{equation*}
    Thus the unnormalized probabilites are sufficient to decide which outcome of \(Y\) is more probable for a given \(X\) without needing to know the full distribution \(P(X)\text{.}\) All we need are: The conditional distributions \(P(X \mid Y=y_i)\text{,}\) and The prior probabilities \(P(Y=y_i)\text{,}\) i.e., the marginal probabilities of each outcome of \(Y\text{.}\)
    If \(Y\) is a discrete variable with \(K\) classes, then, you would just use the function \(arg\ max\text{.}\)
    \begin{equation*} y_\text{pred} = \arg\max_y \bigg[ P(X \mid Y=y) P(Y=y) \bigg] \end{equation*}
    Basically, arg max goes over the list of values generated on the right side for various values of \(y\text{,}\) i.e., for \(y_1, y_2, \cdots, y_K\text{,}\) and then outputs the index of \(y\text{,}\) which corresponds to the largest value in the list. If you have ties, then it outputs the first in the list. You can also have it printout all the items in the tie and output one randomly from that sublist.

    Subsection 2.6.1 Naive Bayes Algorithm

    The Naive Bayes algorithm applies Bayes’ theorem under a simplifying assumption: the features of \(X = (X_1, X_2, \ldots, X_r)\) are conditionally independent given the class label \(Y\text{.}\) Formally,
    \begin{gather*} P(X_1, X_2, \ldots, X_r \mid Y) = \prod_{k=1}^{r} P(X_k \mid Y). \end{gather*}
    This assumption is rarely true in practice, but it makes the computation of \(P(X \mid Y)\) tractable, and the resulting classifier often performs surprisingly well.
    Substituting this factorization into Bayes’ theorem, we obtain
    \begin{gather*} P(Y \mid X) \propto P(Y) \prod_{k=1}^{r} P(X_k \mid Y). \end{gather*}
    A Naive Bayes classifier assigns the label
    \begin{gather*} y_\text{pred} = \arg\max_y P(Y=y) \prod_{k=1}^{r} P(X_k \mid Y=y). \end{gather*}
    Example: Suppose we want to classify whether an email is “spam” or “not spam” based on two binary features: \(X_1 =\) “contains the word ‘free’” and \(X_2 =\) “contains the word ‘money’.” From training data we estimate:
    \begin{align*} \amp P(Y=\text{spam}) = 0.4, \quad P(Y=\text{not spam}) = 0.6,\\ \amp P(X_1=1 \mid Y=\text{spam}) = 0.7, \quad P(X_1=1 \mid Y=\text{not spam}) = 0.1,\\ \amp P(X_2=1 \mid Y=\text{spam}) = 0.6, \quad P(X_2=1 \mid Y=\text{not spam}) = 0.05. \end{align*}
    If an email contains both words (\(X_1=1, X_2=1\)), then
    \begin{align*} \amp P(Y=\text{spam} \mid X)\propto \\ \amp \qquad P(Y=\text{spam}) P(X_1=1\mid Y=\text{spam}) P(X_2=1\mid Y=\text{spam}) \\ \amp\qquad\qquad = 0.4 \times 0.7 \times 0.6 = 0.168,\\ \amp P(Y=\text{not spam} \mid X) \propto \\ \amp \quad P(Y=\text{not spam}) P(X_1=1\mid Y=\text{not spam}) P(X_2=1\mid Y=\text{not spam}) \\ \amp\qquad\qquad = 0.6 \times 0.1 \times 0.05 = 0.003. \end{align*}
    Since \(0.168 > 0.003\text{,}\) the classifier predicts “spam”.
    Example: Suppose we want to classify whether an email is “spam” or “not spam” based on two binary features: \(X_1 =\) “contains the word ‘deal’” and \(X_2 =\) “contains the word ‘win’.” From training data we estimate:
    \begin{gather*} P(Y=\text{spam}) = 0.4, \quad P(Y=\text{not spam}) = 0.6,\\ P(X_1=1 \mid Y=\text{spam}) = 0.7, \quad P(X_1=1 \mid Y=\text{not spam}) = 0.5,\\ P(X_2=1 \mid Y=\text{spam}) = 0.7, \quad P(X_2=1 \mid Y=\text{not spam}) = 0.5. \end{gather*}
    Now consider three scenarios: If the email contains only “deal” (\(X_1=1, X_2=0\)):
    \begin{gather*} P(Y=\text{spam} \mid X) \propto 0.4 \times 0.7 \times (1-0.7) = 0.084,\\ P(Y=\text{not spam} \mid X) \propto 0.6 \times 0.5 \times (1-0.5) = 0.150. \end{gather*}
    The classifier predicts “not spam”. If the email contains only “win” (\(X_1=0, X_2=1\)):
    \begin{gather*} P(Y=\text{spam} \mid X) \propto 0.4 \times (1-0.7) \times 0.7 = 0.084,\\ P(Y=\text{not spam} \mid X) \propto 0.6 \times (1-0.5) \times 0.5 = 0.150. \end{gather*}
    Again the classifier predicts “not spam”. If the email contains both words (\(X_1=1, X_2=1\)):
    \begin{gather*} P(Y=\text{spam} \mid X) \propto 0.4 \times 0.7 \times 0.7 = 0.196,\\ P(Y=\text{not spam} \mid X) \propto 0.6 \times 0.5 \times 0.5 = 0.150. \end{gather*}
    Now the classifier predicts “spam”.

    # Naive Bayes spam classifier with confusion matrix
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.metrics import classification_report, confusion_matrix
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import MultinomialNB
# -----------------------
# 1. Load dataset
# -----------------------
# Use a GitHub-hosted copy of the SMS Spam Collection dataset
url = "https://raw.githubusercontent.com/justmarkham/DAT8/master/data/sms.tsv"
df = pd.read_csv(url, sep="\t", names=["label", "message"])
print("Dataset shape:", df.shape)
print(df.head())
# -----------------------
# 2. Preprocess
# -----------------------
df["label"] = df["label"].map({"ham": 0, "spam": 1})
X_train, X_test, y_train, y_test = train_test_split(
    df["message"], df["label"], test_size=0.2, random_state=42
)
# Convert text to bag-of-words
vectorizer = CountVectorizer(stop_words="english")
X_train_vec = vectorizer.fit_transform(X_train)
X_test_vec = vectorizer.transform(X_test)
# -----------------------
# 3. Train model
# -----------------------
model = MultinomialNB()
model.fit(X_train_vec, y_train)
# -----------------------
# 4. Evaluate
# -----------------------
y_pred = model.predict(X_test_vec)
cm = confusion_matrix(y_test, y_pred)
plt.figure(figsize=(5, 4))
sns.heatmap(
    cm,
    annot=True,
    fmt="d",
    cmap="Blues",
    xticklabels=["Ham", "Spam"],
    yticklabels=["Ham", "Spam"],
)
plt.xlabel("Predicted")
plt.ylabel("Actual")
plt.title("Confusion Matrix")
plt.tight_layout()
plt.show()
print("\nClassification Report:\n")
print(classification_report(y_test, y_pred, target_names=["Ham", "Spam"]))
