    Section 2.7 Model Selection

    Suppose you have trained more than one model using the same training data and would like to choose the best among them. That is, you have a number of trained/estimated predictors, \(\hat{f}_1(X), \hat{f}_2(X), \cdots, \hat{f}_q(X)\) and we want to pick “best” among them. This task is called model selection. It is done using a part of the training dataset that is called validation data as we explain below.

    Subsection 2.7.1 Validation Data

    Since, in the model selection, we cannot yet use the set-aside test dataset to evaluate the final model, you need to set aside a part of your training data itself for the model selection step. This dataset is called validation data. Unlike the set-aside dataset, which is used only on the final model, you can use the validation data as many times as needed during the training.
    Peviously, we used \(n\) datapoints as training and \(m\) datapints as set-aside test dataset. Now, we will have three datasets \(n_{t}\) training examples, \(n_{v}\) validation examples and \(m\) testing examples. The proportion of total data that should be placed in the three bins varies from project to project and availability of data. If we have plenty of data to work with, a common breakdown is shown in Figure 2.7.1.
    Often we do not have the luxury of plenty of data. Then, we have to be creative how to split all the data that we have to work with into three categories. First, you must set aside a reasonable amount for testing, say \(20\%\text{,}\) for the final model evaluation. Then, you treat the entirety of the rest of the data as both training and validation data, but you do not use the same datapoints in both in any one training cycle. Let’s call this set a combined training dataset. Now, we can choose from several strategies to implement the cross-validation.
    1. Leave p out cross validation (LOOCV). You do multiple runs through the combined training data, and in each cycle, you leave different \(p\) examples out for validation and use the rest for training. That is, you never use the examples you used for training as validation. In an extereme case of this strategy, there is Leave One Out policy, when \(p=1\text{.}\)
    2. A more common strategy is K-fold cross-validation. In each training cycle, you split the combined training data into \(K\) equally sized folds. You use \(K-1\) of these fold for training and one fold for validation as illustrated in Figure 2.7.2.
      In a stratified K-fold cross-validation, you attempt to ensure that each fold has the same proportions of each class. The stratified K-fold is specially important if you have an imbalanced data, which happens when one class or a number of classes are either over-represented or underrepresented in the dataset.

    Subsection 2.7.2 Generalization Error

    After training any model, we want the model to perform well on new data. The error on a new data that was not used in the training of the model, is called generalizaton error or out-of-sample error. This error gives us the clearest picture of how the trained model will perform in the “real” world.
    Let us illustrate this concept in the context of a regression task of a quantitative or interval target variable \(Y\) and a \(r\)-dimensional feature vector \(X\) with error being the square error. With the trained predictor \(\hat f(X)\text{,}\) the squared error (a random variable) will be
    \begin{equation} \mathcal{L}(Y, \hat f(X)) = \left( Y - \hat f(X)\right)^2.\tag{2.7.1} \end{equation}
    If you evaluate it’s expectation in the training dataset \(\mathcal{D}_t = \{ (x^{(i)}), y^{(i)}), i = 1, 2, \cdots, n_t \}\text{,}\) we call the result the training error or in-sample error.
    \begin{equation*} \mathcal{L}_\text{in} = \frac{1}{n_t}\sum_{i=1}^{n_t}\, \left( y^{(i)} - \hat f(x^{(i)})\right)^2. \end{equation*}
    This is of course of not much use since this error is on the same datapoints that were used to produce the trained model \(\hat f(X)\) in the first place. It is mostly used for diagnositc purposes since this error shoudl go down with each training of the model as the model “learns” to fit better and better to the training dataset.
    Evaluating the error of Eq. (2.7.1) on a new data \(\left( x^{(0)}, y^{(0)} \right)\text{,}\) we will get
    \begin{equation*} \mathcal{l}^{(0)} = \left(y^{(0)} - \hat f(x^{(0)})\right)^2. \end{equation*}
    The expectation of the error on a validattion dataset \(\mathcal{D}_v\) will be
    \begin{equation*} \mathcal{L}_\text{val} = \frac{1}{n_v}\sum_{i=1}^{n_v}\, \left( y^{(i)} - \hat f(x^{(i)})\right)^2. \end{equation*}
    This is an out-of-sample or generalization error. We use validation error to decide among competing models. Similarly, on a set-aside test dataset,
    \begin{equation*} \mathcal{L}_\text{test} = \frac{1}{m}\sum_{i=1}^{m}\, \left( y^{(i)} - \hat f(x^{(i)})\right)^2. \end{equation*}
    This is also an out-of-sample or generalization error. We use this test error to evaluate the final model.

    Subsection 2.7.3 Sources of Generalization Error

    To understand the various sources of generalization errors let us look more closely at the expected error in a single input vector \(x^{(0)}\text{.}\)
    \begin{equation} \mathcal{L}^{(0)} = \left(Y - \hat f(x^{(0)})\right)^2.\tag{2.7.2} \end{equation}
    Here the trained prediction model \(\hat f\) depends on the training dataset \(\mathcal{D}_t\text{.}\) Now, notice that the sample \(\mathcal{D}_t\) is itself a random sample from the unknown joint distribution \(\rho_{XY}\text{.}\) This results in a distribution of \(\hat f\) itself. We just need mean and variance of \(\hat f\) for the purpose of assessing the squared error. Let us define them by the following expectation values with respect to \((X,Y)\) distribution.
    \begin{align*} \amp \langle \hat f \rangle = \mathbb{E}_{XY}[\hat f] \\ \amp Var(\hat f) = \mathbb{E}_{XY}\left[\left( \hat f - \langle \hat f \rangle \right)^2\right] \end{align*}
    We can also obtain the expectation by averaging over all possible sample datasets \(\mathcal{D}_t\) from the \((X,Y)\)-space. We usually write this averaging process as follows.
    \begin{align*} \amp \langle \hat f \rangle = \mathbb{E}_{\mathcal{D}_t}[\hat f] \\ \amp \text{Var}(\hat f) = \mathbb{E}_{\mathcal{D}_t}\left[\left( \hat f - \langle \hat f \rangle \right)^2\right] \end{align*}
    In Eq. (2.7.2), we now are left with handling \(Y\text{,}\) which we can model by a random Gaussian noise added to the “true” functional relation \(f(X)\) as follows.
    \begin{equation} Y = f(X) + \epsilon,\qquad \epsilon \sim \mathcal{N}(0, \sigma_\epsilon^2).\tag{2.7.3} \end{equation}
    Now, the expectation with respect to \(Y\) for a given \(X = x^{(0)}\text{,}\) will be just expectation with respect to the noise variable \(\epsilon\text{.}\) That is, for the mean and variance of \(Y\) you would get
    \begin{align*} \amp \mathbb{E}_{XY}[Y] = f(x^{0}) + \mathbb{E}_{\epsilon}[\epsilon] = f(x^{0}) + 0 = f(x^{0}).\\ \amp \text{Var}(Y) = \text{Var}(f(x^{0})) + \text{Var}(\epsilon) = 0 + \sigma_\epsilon^2. \end{align*}
    Note that \(f(x^{0})\) is a fixed number and therefore, it’s variance is zero. From this and that \(Var(Y) = \mathbb{E}[Y^2] + (\mathbb{E}[Y] )^2\text{,}\) we can easily surmize that
    \begin{equation} \mathbb{E}_{XY}[Y^2] = \text{Var}(Y) + \left( f(x^{0}) \right)^2.\tag{2.7.4} \end{equation}
    We will use this relation below.
    Now, we have the pieces to find the expectation of the error variable in Eq. (2.7.2) for a given input \(X=x^{(0)}\text{.}\)
    \begin{align*} \mathbb{E}_{XY}[\mathcal{L}^{(0)}]\amp = \mathbb{E}_{XY}\left[\left(Y - \hat f(x^{(0)})\right)^2\right].\\ \amp= \mathbb{E}_{D_t,\epsilon}\left[\left( \epsilon + f(x^{(0)}) - \hat f(x^{(0)})\right)^2\right]. \\ \amp = \mathbb{E}_{D_t,\epsilon}[\epsilon^2] + 2\mathbb{E}_{D_t,\epsilon}[\epsilon\, (f(x^{(0)}) - \hat f(x^{(0)})) ] + \mathbb{E}_{D_t,\epsilon}\left[ \left( f(x^{(0)}) - \hat f(x^{(0)})\right)^2\right] \\ \amp = \sigma_\epsilon^2 + 0 + \mathbb{E}_{D_t}\left[ \left( f(x^{(0)}) - \hat f(x^{(0)})\right)^2\right] \end{align*}
    In the last step, the middle term is zero since \(\epsilon\) factors out and its expectation is zero. Now, we introduce expectation of \(\hat f\text{,}\) to be denoted by \(\langle\hat f(x^{(0)})\rangle\text{,}\) inside the last term as a plus and a minus term.
    \begin{align*} \mathbb{E}_{XY}[\mathcal{L}^{(0)}] \amp = \sigma_\epsilon^2 + \mathbb{E}_{D_t}\left[ \left( f(x^{(0)}) - \langle\hat f(x^{(0)})\rangle + \langle\hat f(x^{(0)})\rangle - \hat f(x^{(0)})\right)^2\right] \end{align*}
    Here
    \begin{equation*} \langle\hat f(x^{(0)})\rangle \equiv \mathbb{E}_{D_t}\left[ \hat f(x^{(0)}) \right]. \end{equation*}
    Now, we group the last term into two groups:
    \begin{equation*} a = f(x^{(0)}) - \langle\hat f(x^{(0)})\rangle,\quad b = \langle\hat f(x^{(0)})\rangle - \hat f(x^{(0)}). \end{equation*}
    When we expand \((a + b)^2 = a^2 + b^2 + 2 a b\text{,}\) the expectation of the cross-term truns out to be zero as the following series of steps demostrates.
    \begin{align*} \mathbb{E}_{D_t}[ a\, b]\amp = \mathbb{E}_{D_t} \left[ \left( f(x^{(0)}) - \langle\hat f(x^{(0)})\rangle\right)\, \left( \langle\hat f(x^{(0)})\rangle - \hat f(x^{(0)})\right) \right]\\ \amp = \mathbb{E}_{D_t} \left[ f(x^{(0)}) \, \left( \langle\hat f(x^{(0)})\rangle - \hat f(x^{(0)})\right) \right] \\ \amp \qquad - \mathbb{E}_{D_t} \left[ \langle\hat f(x^{(0)})\rangle\, \left( \langle\hat f(x^{(0)})\rangle - \hat f(x^{(0)})\right) \right]\\ \amp =f(x^{(0)}) \, \mathbb{E}_{D_t} \left[ \langle\hat f(x^{(0)})\rangle - \hat f(x^{(0)}) \right] \\ \amp \qquad - \langle\hat f(x^{(0)})\rangle\, \mathbb{E}_{D_t} \left[ \langle\hat f(x^{(0)})\rangle - \hat f(x^{(0)}) \right]\\ \amp = 0 + 0 = 0. \end{align*}
    The expectation of \(a^2\) is just \(a^2\) itself, since the random variable \(\hat f\) inside it already averaged over.
    \begin{equation*} \mathbb{E}_{D_t}[a^2] = a^2 = \left( f(x^{(0)}) - \langle\hat f(x^{(0)})\rangle \right)^2. \end{equation*}
    Therefore, only the expectations of \(b^2\) remain in the abstract form giving us the final expression for the expectation of the generalization error on a single datapoint, \(X=x^{(0)}\text{.}\)
    \begin{equation} \mathbb{E}_{XY}[\mathcal{L}^{(0)}] = \sigma_\epsilon^2 + \left( \langle\hat f(x^{(0)})\rangle - f(x^{(0)}) \right)^2 + \mathbb{E}_{D_t}\left[ \left(\hat f(x^{(0)}) - \langle\hat f(x^{(0)})\rangle \right)^2 \right]\tag{2.7.5} \end{equation}
    The error has three terms: the first term is called the irreducible error - it is completely model-independent and is inherent to the statistical nature of the variables themselves. The second term is the square of how different the expected model over all training sets is different from the true value at the datapoint. This is called bias of the model.
    \begin{equation*} \text{Bias } = \langle\hat f(x^{(0)})\rangle - f(x^{(0)}). \end{equation*}
    Since, this term appear as a square, only the relative sign matters. It’s contribution to the error is called Bias\(^2\). The last term in the error is the variance of the model in its distribution. Basically, model will change with different training samples, resulting in a collection of models, and this error comes from how variable various models would be from the mean model, which is designated here by \(\langle\hat f(x^{(0)})\rangle\text{.}\)
    Summarizing,
    \begin{equation} \textbf{Generalization Error} = \textbf{Irreducible} + \textbf{Bias}^2 + \textbf{Variance}.\tag{2.7.6} \end{equation}
    This result is called Bias-Variance Decomposition of the expected error. Altough, we have arrived at it by examining squared error for a regression task, one can show that the decomposition is general and works out for other tasks as well. We will see below that this decomposition is important in understanding how to handle complexity in models. For instance, more complex models, i.e., models with higher degrees of freedoms tend to have less Bias squared error but higher Variance error. That is, there is a tradeoff between reducing Bias squared error and Variance error when selecting the complexity of models.
